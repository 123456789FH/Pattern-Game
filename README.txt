نظام اللعب:
- القفزة الصحيحة: +١٠ نقاط + عملة
- كل ٣ إجابات صحيحة متتالية: مكافأة عملتين إضافيتين
- القفزة الخاطئة: −٥ نقاط + فقدان محاولة
- ثلاث محاولات لكل مرحلة
- من ١ إلى ٣ نجوم عند إنهاء المرحلة
- فتح المرحلة التالية تلقائيًا
- حفظ التقدم محليًا على الجهاز
- مؤثرات صوتية قصيرة فقط، بلا موسيقى

١) افتح index.html في المتصفح للتجربة الأساسية.

٣) لا تغيّر أسماء الملفات أو المجلدات إلا إذا عدلت المسارات داخل الكود.
